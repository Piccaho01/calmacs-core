CALMAC'S CORE

A live pixel-art superhero/villain HQ that visualizes your AI agent crew working in real time.

What it is

A reskin of the open-source Claude-Office (MIT) — an isometric pixel-art base where your Claude Code agents appear as little avatars, walk to desks, work, and chat. Rebranded top to bottom as Calmac's Core, cast with a Marvel/DC crew, and themed as a split hero-wing / villain-lair HQ.

Engine: Claude Code hooks + WebSocket → Express server → React frontend. Real agent spawns show up live.

Key features

  • Always-on: auto-launches when the home PC boots and runs in the background (desktop app launch-on-startup / Windows startup task). Tray badge + mini widget.
  • Consult-the-boss flow: when you assign a task, the hero NPC walks over to your boss NPC, they discuss it, and only then confirm and start work.
  • You are the sky-god / boss — heroes look up to you; click any NPC to inspect what they're doing, every tool they've called, and what they've said.
  • Live events: permission prompts raise a hand with a chime (answer from the office); failed deploys turn the HQ red; the whiteboard shows the real task list; cost/token/context meters per session.

HQ reskin — one base, two wings

  • Watchtower bright hero command center (Build team) — holo-displays, mission table, blue/teal glow.
  • The Lair dark villain den (Break team) — server banks, red lighting, danger stripes.
  • Central Core the neutral hub — Venom, Alfred, and the boss (you) preside. This is "Calmac's Core."

Environment is sprites + CSS, so it's reskinnable: floor tiles, furniture → consoles/lab stations, palette in office.css.

Sprite pipeline

Cute-but-modern pixel avatars that actually look like each character.

  1. Open ChatGPT (image generation).
  2. Upload public/sprites/characters/Helper.png as the style reference.
  3. Prompt for the character in the same style + 4-pose layout: Front-Left · Rear-Right · Front-Right · Rear-Left, one row, white background, no text.
  4. Save the PNG → extract with python3 scripts/extract-boss-sprite.py your-character.png Name-1.

Nightcrawler (Art lead) owns the prompts and QAs each returned sheet against the style bible.

Access model

  • Code lives on your GitHub → accessible from phone and PC. Nothing on the work laptop.
  • The running office lives on the home PC (local server, binds to 127.0.0.1).
  • Phone watches it via Remote Control into the PC; direct phone hosting of the live office is the "hassle" path (localhost-only by design) and is skipped for now.

Reference repo: Claude-Office by W17ant (MIT). This spec is a working plan — details firm up during the build.
